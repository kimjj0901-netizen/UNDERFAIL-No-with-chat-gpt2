# UNDERFAIL 원작 상황 대응표

## 문서 상태

- 상태: `Proposal`
- 목적: 원작의 진행 순서를 UNDERFAIL의 기존 인물·학교 공간에 대입
- 상세 문서: [STORY_SCRIPT.md](./STORY_SCRIPT.md)
- 우선 기준: 사용자가 직접 작성한 [CREATIVE_DECISION_WORKBOOK.md](../CREATIVE_DECISION_WORKBOOK.md)와 [STORY_CONTROL_PANEL.md](../STORY_CONTROL_PANEL.md)

이 문서는 새 사건을 창작하는 문서가 아니다. 사용자가 직접 작성한 학교·가족·전투·장비 설정을 바꾸지 않고, 원작에서 발생하는 상황의 순서와 기능을 그 설정에 대입한다. 대응하지 않는 요소는 임의로 채우지 않는다.

## 원작 대응에서 유지할 것

- 보호자와의 분리는 초반에 발생한다.
- 첫 주요 경쟁자는 Snowdin 기능 구간에 배치한다.
- 추격자·동경하는 조연·특수 인형형 전투는 Waterfall 기능 구간에 묶는다.
- 과학자·방송형 보스·조건부 상점은 Hotland 기능 구간에 묶는다.
- 숨은 연구 구역은 True Lab 기능 구간에 둔다.
- 최종 통치자와 가족사는 New Home 기능 구간 뒤에 둔다.
- 루트 변화는 지역별 일반 만남 소진, 전투 결과, 비전투 해결, 관계와 재방문으로 표현한다.

## 원작 대응에서 새로 만들지 않을 것

- 원작에 대응하지 않는 별도 학생회 보스
- 출석부·시간표·종을 본편 핵심 사건으로 만드는 독자적 플롯
- 새 가족사와 새 제도 역사를 임의로 확정
- 대응표에 없는 신규 인물의 주요 보스화
- 원작의 대사·고유 농담·문장 구조 복제

구체적인 UNDERFAIL 사건은 사용자가 기존 문서에서 확정한 내용만 사용하며, 나머지는 `Proposal`로 남긴다.
