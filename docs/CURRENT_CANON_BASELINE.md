# UNDERFAIL 최신 정사 기준선

## 목적

이 문서는 이전 초안과 새 제안을 섞지 않기 위해, [chat.json](../chat.json), 사용자가 직접 작성한 [CREATIVE_DECISION_WORKBOOK.md](../CREATIVE_DECISION_WORKBOOK.md), [STORY_CONTROL_PANEL.md](../STORY_CONTROL_PANEL.md)의 사용자 작성 내용을 우선해 정리한 기준선이다. 다른 문서와 충돌하면 사용자 워크북의 직접 작성 내용과 이 문서의 `사용자 확정`을 우선하고, `보류`는 임의로 확정하지 않는다.

## 사용자 확정 또는 최신 합의

### 작품 방향

- UNDERFAIL은 Undertale처럼 체계적인 스토리, 행동에 따라 달라지는 사건, 뒤늦게 회수되는 복선을 가진 게임을 목표로 한다.
- 풍화양상 고등학교를 배경으로 하며 현실 학교와 완전히 같지 않은 판타지 세계다.
- 발로란트 계열 인물이 포함되므로 일반적인 현실 학교물로 제한하지 않는다.
- 전투에는 세계관상 실제 살해 기능이 있다.
- 스토리를 먼저 완성하고 게임 구현은 그 뒤에 진행한다.
- 사용자가 모든 세부 스토리를 직접 작성하지 않아도 되도록, 핵심 결정만 사용자가 정하고 세부 연결은 작성자가 담당한다.
- 주인공은 각종 시험 점수와 생활기록을 바탕으로 성적이 낮아 학교에 배정된다.
- 주인공의 특정 예체능 진로보다 자유로운 진로 선택권이 중심 목표다.
- 먼저 떨어진 선배들의 예체능 물품이 장비가 되며, 장비에 따라 공격 방식과 능력치가 달라진다.
- 체력 고갈 패배는 수업에 갇히는 듯한 연출과 의지·체크포인트 계열 문구를 참고한다.

### 핵심 인물과 기능

- **도미토리엘:** 초반 보호자이자 교육복지반 담당자. 학교의 표적이 되는 학생을 보호한다.
- **도미토리엘의 초반 대립:** 주인공을 낙제생반에서 나가지 못하게 막지만, 공격 없이 자신의 꿈을 향한 의지를 반복하면 보낸다.
- **아스도어 스톨민트:** 교장이자 최종 보스. 도미토리엘의 남편이며 불리의 아버지.
- **불리:** 플라위·아스리엘 기능을 변형한 인물. 두 사람의 아들이며 주인공을 시험한다.
- **불리의 첫 장면:** 교문에서 술과 담배를 권하며 탄막형 튜토리얼 전투를 시작하고, 도미토리엘에게 날아가 욕설과 함께 사라진다.
- **파프리카:** 파피루스 기능을 변형한 인물. 첫 주요 보스급 인물.
- **체임버쌤:** 언다인 기능을 변형한 추격자·강력한 전투 인물.
- **SANZ:** 샌즈 기능을 변형한 관찰자.
- **알파이썬:** 알피스 기능을 변형한 정보 교사.
- **머핀:** 머펫 기능을 변형한 인물.
- **너드스타블룩:** 냅스타블룩 기능을 변형한 인물.
- **빠나!!:** 테미 기능을 변형한 인물 또는 집단적 코미디 요소.
- **모델스 튜던트:** 매드 더미 기능을 변형한 인물. 쌍둥이와 공부를 방해받았다는 이유로 주인공과 대립한다.
- **디버그 스톤:** 정보 교사·가스터 기능을 변형한 인물.
- **크롬북 계열:** 버전까지 포함한 풀네임을 사용한다. Lenovo Chromebook, Samsung Chromeboom, MSI Titan 계열은 서로 다른 형태와 루트 기능으로 구분한다.
- **알파이썬:** 단순 교육용 크롬북을 만들었으나 주인공을 보며 강화를 해제하려다가 반-열등생 척살 프로토콜을 잘못 설정한 제작자다.
- **아스도어의 과거:** 과거에는 예체능과 기타 진로를 응원했지만 타 학교와의 경쟁에서 학생과 학교를 잃었다고 믿어 통제 교육을 고수한다.
- **아스도어의 타협:** 꿈을 포기하고 공부하면 좋은 대학으로 보내 주겠다고 제안한다.
- **모델스 튜던트의 전투:** 팬클럽 유도 공격, 필기구 최후 공격, 너드스타블룩의 만화 권유와 도주를 유지한다. 강경 루트에서 비공격 행동이나 자비를 선택하면 강경 진행이 탈선한다.

- 저장·재시작이 세계관에 영향을 주는지

- 주인공 세부 성격·첫 친구 이름·학생회 임원 이름 등 워크북에서 보류된 항목

## 문서 사용 규칙

- 기존 문서의 추천 이름과 임시 설정은 사용자 확정으로 승격하지 않는다.
- `STORY_MASTER_BIBLE.md`는 이전에 작성된 통합 Proposal이므로 이 기준선과 대조해 사용한다.
- 원작 조사 자료는 구조·기능·인물 성향 분석에만 사용한다.
- 원작의 대사를 그대로 옮기거나 비슷한 문장을 재작성하지 않는다.
